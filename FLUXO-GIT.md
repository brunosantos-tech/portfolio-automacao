# Fluxo de trabalho com Git

1. Atualizar a branch principal.
2. Criar uma branch para a tarefa.
3. Fazer as alterações necessárias.
4. Revisar as mudanças com git diff.
5. Preparar os arquivos com git add.
6. Registrar as alterações com git commit.
7. Enviar a branch com git push.
8. Abrir um Pull Request.
9. Revisar e integrar as alterações à main.
10. Atualizar a branch main local.
